## Decisions Made
1. Field-aware comparison over n-grams: Parsing structured headings into fields gives perfect separation of numeric values. Simpler and more robust than bigram matching.
2. Skip only > 6M (not ≥ 6M): At exactly 6M the accelerated condition still gets updated (last valid data point).
3. Skip means "leave untouched": 40°C/75%RH images and tables stay in the document, they just aren't replaced with tracked changes.
4. Asymmetric skip implementation is acceptable: figures.py uses regex on headings, tables.py uses inline tuple check — each matches how that script already processes data.
5. Declined to fix review findings #3 (field count asymmetry), #9 (fallback heading check), #15 (code symmetry) — low real-world risk given the stable data pipeline.
